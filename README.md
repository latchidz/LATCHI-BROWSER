# LATCHI BROWSER

**متصفح ويندوز مكتبي حقيقي وخفيف** — مبني على محرك Microsoft Edge WebView2 (Chromium): تبويبات حقيقية، حسابات Google متعددة بجلسات معزولة، إضافات متصفح، تنزيلات، مفضلة، سجل، ومساعد Gemini AI.

> **LATCHI Browser is an independent project and is not affiliated with Microsoft, Google or the Chromium project.**
> المحرك هو WebView2 Runtime الرسمي من Microsoft؛ المواقع تعمل بمحركها الأصلي كما هي.

---

## لماذا؟

متصفح كامل (Chrome/Edge) يستهلك ذاكرة كبيرة على الأجهزة الضعيفة. **LATCHI Browser** يعطيك متصفحاً حقيقياً بلا الحِمل الزائد: نافذة واحدة، محرك واحد مشترك، تبويبات تُنشأ عند الحاجة فقط، وإدارة موارد صارمة.

## المعمارية

```
LATCHI Browser (WPF / .NET 8, x64)
│
├── CoreWebView2Environment واحدة مشتركة (كل شيء منها — لا بيئة لكل تبويب)
│
├── TabManager — كل تبويب = WebView2 من نفس البيئة (إنشاء عند الطلب)
│
├── BrowserCore (منطق صرف، مُختبَر): URL resolution، محركات البحث، الإعدادات
│
└── (الجولات القادمة) Profiles متعددة · Extensions · Downloads · Bookmarks · History · AI
```

- **بيئة واحدة مشتركة** لكل التبويبات والنوافذ (توصية Microsoft الرسمية للأداء)
- **Lazy loading**: لا يُنشأ أي WebView قبل الحاجة إليه
- **تسريع العتاد مفعّل دائماً** (الفيديو وWebGL يحتاجانه)
- بيانات المستخدم في `%LOCALAPPDATA%\LATCHI\Browser` (لا Program Files أبداً)

## الاختبارات

منطق Core كله مُختبَر (xUnit، يعمل على أي نظام): تحليل العناوين، محركات البحث، الإعدادات (بما فيها ملف تالف)، وحارس XAML يمنع فئة انهيار Color-vs-Brush نهائياً. البناء في GitHub Actions على ويندوز حقيقي.
