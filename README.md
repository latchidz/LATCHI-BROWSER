# LATCHI BROWSER

**متصفح ويندوز مكتبي حقيقي وخفيف** — مبني على محرك Microsoft Edge WebView2 (Chromium): تبويبات حقيقية، حسابات Google متعددة بجلسات معزولة، إضافات متصفح، تنزيلات، مفضلة، سجل، ومساعد Gemini AI.

> **LATCHI Browser is an independent project and is not affiliated with Microsoft, Google or the Chromium project.**
> المحرك هو WebView2 Runtime الرسمي من Microsoft؛ المواقع تعمل بمحركها الأصلي كما هي.

---

## التحميل

من صفحة [Releases](https://github.com/latchidz/LATCHI-BROWSER/releases) — الإصدار **v1.2.0**:

- **Setup** — مثبّت per-user بلا صلاحيات مسؤول (اختصار سطح مكتب اختياري، إلغاء تثبيت نظيف)
- **portable.zip** — نسخة مكتفية ذاتياً؛ فك الضغط وشغّل `LATCHI-BROWSER.exe`
- **SHA256SUMS.txt** — بصمات الملفات

يتطلب Windows 10/11 x64 مع WebView2 Evergreen Runtime (مثبّت افتراضياً على ويندوز 11).

## المزايا (v1.2.0)

- **بداية فورية بلا إجبار** — أول تشغيل: اختيار اللغة ثم زر **«ابدأ التصفح»** يفتح المتصفح مباشرة. زر «إضافة حساب Google» ثانوي واختياري تماماً — المتصفح يعمل بالكامل بدونه (تصفح، تبويبات، فيديو، تنزيلات، مفضلة، سجل، إضافات)
- **لا تجميد عند الإقلاع** — الصفحة الرئيسية تظهر فوراً والمحرك يجهز في الخلفية بصمت (لا يظهر أي نص «جارٍ التشغيل») — إصلاح مشكلة عدم استجابة الماوس في شاشة البداية القديمة
- **صفحة رئيسية LATCHI حقيقية** — بحث كبير + **وصول سريع قابل للتعديل بالكامل** (إضافة/تعديل/حذف أي اختصار: زر أيمن على البلاطة) + صفوف **المفضلة** و**الزيارات الأخيرة** + بلاطة Google الرسمية بأربعة ألوانها
- **خلفية قابلة للتخصيص** — من زر «تخصيص الصفحة»: داكن / لون جاهز / صورة من جهازك (تُنسخ خفيفة إلى مجلد البيانات) / إزالة
- **استعادة الجلسة** — عند التشغيل تعود التبويبات المفتوحة (اختياري من الإعدادات) مع **تحميل كسول**: التبويبات تظهر فوراً ولا يُنشأ webview إلا للتبويب الذي تفتحه فعلاً — خفيف على الأجهزة الضعيفة
- **قائمة تبويب كاملة** — زر أيمن على أي تبويب: تكرار / إغلاق / إغلاق الأخرى / إغلاق ما على اليمين / إعادة فتح المغلق
- **محرّك تصفح حقيقي** — WebView2 (Chromium) ببيئة واحدة مشتركة وGPU مفعّل دائماً، يعمل بشكل غير مرئي تماماً
- **تبويبات حقيقية** — فتح/إغلاق/تبديل، Ctrl+T / Ctrl+W / Ctrl+Shift+T / Ctrl+Tab، إغلاق بالزر الأوسط، نسخة مُصلَحة لآخر 25 تبويباً مغلقاً
- **نوافذ متعددة** — Ctrl+N نافذة عادية، Ctrl+Shift+N نافذة خاصة (InPrivate) لا تسجّل سجلاً
- **حسابات متعددة** — مبدّل حسابات في شريط الأدوات: كل حساب بجلساته الخاصة (كوكيز/تخزين) تحت عملية متصفح واحدة مشتركة. تسجيل الدخول إلى Google يحدث **في صفحة Google الحقيقية** داخل المتصفح — التطبيق لا يطلب ولا يرى كلمة السر أبداً، والجلسات تبقى محفوظة
- **Omnibox** — عنوان مباشر أو بحث، مع 3 محركات: Google / Bing / DuckDuckGo (تُختار من الإعدادات)
- **مفضلة** — نجمة بجانب العنوان (Ctrl+D)، شريط مفضلة (Ctrl+Shift+B)، إدارة كاملة (فتح/حذف/مسح)
- **سجل تصفح لكل حساب** — بحث فوري، حذف فردي، مسح كامل (النافذة الخاصة لا تسجّل شيئاً)
- **خصوصية حقيقية** — من الإعدادات: مسح سجل التصفح، مسح الملفات المؤقتة، مسح الكوكيز — عبر واجهات WebView2 الرسمية
- **تنزيلات حقيقية** — تتبع مباشر بشريط تقدم + إيقاف مؤقت/متابعة/إلغاء + فتح الملف + إظهار في المجلد (Ctrl+J)
- **إضافات المتصفح** — تثبيت الإضافات غير المعبّأة (مجلد فيه manifest.json) وتفعيلها/تعطيلها/إزالتها عبر واجهات WebView2 الرسمية
- **Zoom** — Ctrl+Plus / Ctrl+Minus / Ctrl+0
- **DevTools** — F12 أو Ctrl+Shift+I
- **ملء شاشة ذكي** — F11 للمتصفح، وملء شاشة الفيديو من الصفحة نفسها يعمل بشكل مستقل
- **واجهة عربية/إنجليزية** — زر تبديل فوري، منفصلة تماماً عن لغة المواقع
- **LATCHI AI** — مساعد Gemini في شريط جانبي، بمفتاحك الخاص (gemini-2.5-flash أو أي موديل تختاره). **مفتاحك يُخزَّن مشفّراً على جهازك فقط (Windows DPAPI) ولا يُرسل إلا إلى Google.**

## الأمان — قواعد ثابتة

- لا صفحات دخول مزيّفة، لا جمع اعتمادات، لا اعتراض كلمات سر أو tokens
- مفتاح Gemini: تُدخله أنت في الإعدادات → يُشفَّر بـ DPAPI لجهازك → يظهر في أي ملف/لوج/مستودع؟ **أبداً**
- سجل التصفح ملف JSON لكل حساب تحت `%LOCALAPPDATA%\LATCHI\Browser` — تحته يدك دائماً

## القيود المعروفة (معلنة بصدق — لا مواربة)

- **الإضافات**: unpacked فقط (مجلد manifest.json). **لا يوجد تثبيت من Chrome Web Store** — قيد WebView2 الرسمي نفسه
- **لا TrySuspend** عند التصغير: عنصر WPF لا يكشف الـController — نستعمل `MemoryUsageTargetLevel.Low` بدلاً منه (وهو المدعوم)
- لا بحث داخل الصفحة (Find-in-page) — لا واجهة host في WebView2\n- Ask-before-download (السؤال قبل التنزيل) مؤجل
- لا مجلدات مفضلة متداخلة (قائمة مسطحة فقط حالياً)
- ثيم داكن فقط (Light/System theme مؤجل)
- لا واجهة لإدارة صلاحيات المواقع، لا PiP يدوي، لا صفحة New Tab مخصصة، لا Auto-Update (استخدم المثبّت للترقية)
- مساعد AI يرى ما تلصقه له في المحادثة فقط — لا يقرأ الصفحة تلقائياً (page-context مؤجل)

## المعمارية

```
LATCHI Browser (WPF / .NET 8, x64)
│
├── CoreWebView2Environment واحدة مشتركة (كل التبويبات والبروفايلات منها — لا بيئة لكل تبويب)
│
├── ProfileStore / BookmarkStore / HistoryStore — JSON بسيط قابل للفحص، ملف تالف = بداية نظيفة لا انهيار
│
├── DownloadManager — تتبع CoreWebView2DownloadOperation الحية (إيقاف/متابعة/إلغاء حقيقية)
│
├── Gemini client نقي (بناء طلب/تحليل استجابة) — مُختبَر بلا شبكة
│
└── SecureKeyStore — DPAPI CurrentUser لمفتاح Gemini
```

- بيانات المستخدم في `%LOCALAPPDATA%\LATCHI\Browser` (لا Program Files أبداً)
- **قاعدة المشروع الثابتة (§107):** أي زر يظهر في الواجهة يعمل فعلياً — ما لم يُبنَ بعدُ لا يظهر له زر
